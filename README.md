# Exploratory Data Analysis with Pandas

End-to-end data processing pipelines featuring data cleaning, wrangling, aggregation, and exploratory data analysis (EDA).

## 📌 Repository Overview
This repository highlights practical data engineering and analytical workflows, converting raw, noisy datasets into actionable business and engineering insights.

## 🛠️ Data Pipeline Capabilities
* **Data Ingestion & Cleaning:** Handling missing values, duplicates, out-of-bounds anomalies, and data type casting.
* **Data Wrangling:** Complex merges, joins, concats, and feature engineering.
* **Group Aggregation:** Pivoting, multi-indexing, and groupby transformations.
* **Exploratory Data Analysis (EDA):** Detecting statistical distributions, correlations, and trend patterns.
